# 06 速查卡片（贴墙版）

> 一屏看完这套语言。细节回各分册。

---

## 视觉公式

```
浅色底 #F7F9FC
  + 三颗流动光斑（蓝 0.30 / 粉 0.26 / 青 0.22，周期 4.4/4.8/3.6s）
  + 黑白文字（主 100% / 次 62% / 弱 40%）
  + 靛蓝强调 #4F46E5（深色 #A5B4FC）
  + 玻璃浮层（折射 + 边缘光 + 薄雾，不是白板）
```

## 四句口诀

1. **文字黑白，装饰彩色。**
2. **尺寸取值，不许现编。**
3. **玻璃是地基，改附加物别削玻璃。**
4. **会动的自己画，静止的才折射，一堆小的走平面。**

---

## 五条红线

| ✗ | ✓ |
|---|---|
| 靠删折射修方块 | 查离屏层 / 阴影 / 缩放链 / 层级 |
| `Modifier.clip` 裁玻璃 | `clipPath` 只裁玻璃，内容在外 |
| 按下改 Modifier 链长度 | 常驻 `graphicsLayer` 只改参数 |
| 弹窗采样自己所在的内容层 | `LocalInContentLayer` 退回实色膜 |
| 白玻璃不描暗边 | 1dp 黑 0.05~0.09 扣出形状 |

## 新项目接入顺序

```
1. 搬 Design.kt（档位）      ← 防"不像一套东西"
2. 搬 Theme.kt（黑白文字 + 强调色）
3. 建三层 backdrop 骨架      ← 浮层必须是兄弟节点
4. 按场景选玻璃实现          ← 会动/静止/一堆小件
5. 接光斑 + 反馈 + 安全点击
```

顺序反了会重复踩坑。
