# 02 尺寸与档位

> 来源：徒步小记原生版 `ui/theme/Design.kt`、`GlassWidgets.kt`。
> 这份档位表是因为一次自查发现的：全工程有 **14 种圆角**（2/3/4/5/8/9/10/11/12/13/14/16/17/18）和 **18 种字号**（含 9.5 / 10.5 / 11.5 / 12.5 / 13.5 半号）。每个组件各写各的，界面"能跑但不像一套东西"。

---

## 一、圆角：6 档

| 档位 | 值 (dp) | 用在哪里 |
|---|---|---|
| `Radii.CARD` | 20 | 大卡片、弹窗外壳 |
| `Radii.SUB` | 16 | 子卡片（统计卡、山册卡、列表容器） |
| `Radii.BUTTON` | 12 | 所有按钮、胶囊按钮、分段控件 |
| `Radii.INPUT` | 10 | 输入框、日期格、行内小按钮、代码块 |
| `Radii.PILL` | 6 | 小标签、状态徽章、色条 |
| `Radii.TICK` | 4 | 极小装饰色条（4dp 线、书脊边），只用于细条，不用于可点区域 |

**圆形一律 `CircleShape`，不要写 `rounded(50)`。**

⚠️ 例外：玻璃浮层有自己的圆角（底栏 26dp 胶囊端、弹窗内部另算），那是材质的一部分，不是新增圆角档位。

**规则：新增组件只从这里取值，不许拍一个新数字。**

---

## 二、字号：9 档

| 档位 | 值 | 用途 |
|---|---|---|
| `Type.HERO` | 22sp | 分享卡大标题（唯一例外，导出图专用） |
| `Type.TITLE` | 19sp | 页面主标题、"走完了"这类庆祝标题 |
| `Type.H2` | 16sp | 弹窗标题、月份标题 |
| `Type.H3` | 15sp | 区块小标题（工具行里的"记录/计划/设置"） |
| `Type.BODY` | 14sp | 正文、按钮文字、列表主文本 |
| `Type.LABEL` | 13sp | 次要按钮、卡片标题、表单字段名 |
| `Type.CAPTION` | 12sp | 说明文字、副标题、单位 |
| `Type.TINY` | 11sp | 极小说明、图例、徽章 |
| `Type.MICRO` | 10sp | 角标、脚注（能用 TINY 就别用 MICRO） |

**只有这 9 个值，不要再用半号（11.5 / 12.5 之类）。**

Typo 映射补充：弹窗标题 16sp、弹窗正文 14sp / 行高 21sp、弹窗内按钮 15sp（比容器 15 大一号或齐平，不要比容器小）。

---

## 三、弹窗尺寸：3 档

之前各弹窗自己写 0.80 / 0.84 / 0.86 / 0.88 / 0.90 / 0.92 六种宽度，限高四种——同一个 App 里弹窗一张一个样。

| 档位 | 宽度占屏 | 用在哪里 |
|---|---|---|
| `DialogSize.SM` | 0.80 | 确认类（"删除这个计划？"一两句话） |
| `DialogSize.MD` | 0.88 | 一般弹窗（列表、详情） |
| `DialogSize.LG` | 0.92 | 表单与长正文（编辑记录、隐私政策） |
| `MAX_HEIGHT` | 0.80 | 统一限高，底部永远留出可点边距 |

## 四、常用间距与控件尺寸

这些是从实际实现里收敛出来的，不算"档位"但属于同一套语言：

| 场景 | 值 | 说明 |
|---|---|---|
| 顶栏总高 | 68dp | 实体 50dp + 羽化带 22dp（标题 22sp 时行高必须跟上） |
| 底栏玻璃条高 | 约 60dp | 圆角 26dp，等于胶囊端 |
| 底栏指示胶囊 | 约 48×60dp | 选中态，圆角 = 高度/2 |
| 输入格左右边距 | 12dp | 窄框（"时/分"并排）两边共吃 24dp，需要按需收窄 |
| 描边 | 1dp | 全站标准，不按控件缩放（玻璃内部棱线另有 0.8/1.5dp） |
| 卡片描边色 | `#E2E8F0` | 白卡贴白底时唯一能看出边界的东西 |

## 五、怎么防止档位被破坏

1. **集中定义**：所有档位只在一个文件（`Design.kt`）里，`Radii` / `Type` / `Palette` / `DialogSize` 四个 object。
2. **脚本兜底**：项目里有 `tools/designcheck.py` 做静态扫描，挡住硬编码的野圆角/野字号。
3. **新增先验**：加组件前先问"这几个数字在档位表里吗"，不在就选最近的一档，不要新增。
4. **例外要有理由**：只有分享卡 HERO(22sp) 这种明确"导出图专用"的才允许例外，而且要写进注释。

## 六、错误对照

| 错法 | 后果 |
|---|---|
| 字号用 11.5 / 12.5 半号 | 字号表从 9 档膨胀回 18 档，和 Web 也对不上 |
| 圆角写 `rounded(14.dp)` 因为"看着顺眼" | 又一处野圆角，卡片和按钮不像一套 |
| 弹窗自己写 0.85 宽度 | 限高一乱，底部按钮被挤出屏幕 |
| 系统字体放大时不管 | 固定高度容器被撑破，"内容显示不全" |
| 用 `rounded(50)` 画圆 |  extreme 尺寸下椭圆变形，统一 `CircleShape` |
