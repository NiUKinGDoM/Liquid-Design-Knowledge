# 03 液态玻璃材质

> 来源：徒步小记原生版 `ui/liquid/LiquidGlass.kt`、`ui/Glass.kt`、`ui/GlassOverlay.kt`、`ui/GlassWidgets.kt`、`ui/AppChrome.kt`。
> 依赖：Kyant0/backdrop（Compose 圈液态玻璃事实标准，4.4k star）。
> **这篇是整套语言里最贵的一篇——每个数字背后都有一次返工。**

---

## 一、最高铁律（写在源码文件最顶上）

> **液态玻璃不许瞎改，也不许删掉。**
> 之前为了修一个"方块"，把底栏的折射整个删了改成自绘——用户原话："我的折射呢？？？？"
> 正确做法永远是：**保住玻璃本身，去改造成问题的那个附加物**（离屏层、阴影、裁剪方式、缩放链），绝不用降低玻璃效果来换。

---

## 二、什么是液态玻璃（四个物理特征）

用户指出早期版本"只是模糊而已"——那是 classic glassmorphism（毛玻璃），不是液态玻璃。液态玻璃要有：

| # | 特征 | 实现手段 |
|---|---|---|
| ① | 厚度感 | 边缘"玻璃壁"比中心亮：顶部强高光 + 底部内反光 |
| ② | 色散 | 边缘极细彩虹带（青/品红/靛），`chromaticAberration = true` |
| ③ | 折射暗示 | 内外双描边 + 垂直渐变，制造"光被弯折"观感；真折射靠 lens shader |
| ④ | 弹性 | 按下轻微缩放 + 形变回弹（液体的触感） |

**关键认知：模糊 ≠ 玻璃。真正的存在感来自折射 + 边缘光，不是白雾。** 中心必须保持清透，可读性靠 blur 把背景糊成色块，不靠刷白漆。

## 三、四种玻璃实现，按场景选

项目里踩过"一层 shader 撑不住"的坑后，收敛出四套实现，**不是重复代码，是成本分层**：

| 实现 | 原理 | 用在哪 | 特点 |
|---|---|---|---|
| `liquidGlassSurface` | backdrop + lens + blur | 弹窗、大浮层 | 真折射、真模糊；静止不常驻重绘 |
| `glassBar` | 纯 Canvas 自绘 | 底栏本体 | 零离屏层，不折射但反射全；常驻节点必须无残影 |
| `glassPill` | 纯 Canvas 自绘 + path 裁剪 | 底栏选中胶囊 | 会移动，绝对不能有离屏层 |
| `glassStatic` / `liquidGlassChip` | 平面填充 + 1dp 细边 | 所有按钮、小件 | 10 个同屏 shader 会崩；按钮平面化 |

另有 `glassPanel`：1:1 搬 Web 的 `.glass-panel`——白 0.05 底 + 白 0.11 边 + 20dp 圆角 + 极轻阴影，浅色模式"若隐若现的框"，用于页面分组块。

**选择口诀：会动的、会频繁重绘的 → 自绘；静止的大块 → 真 backdrop；一堆小按钮 → 平面。**

## 四、三层 backdrop

玻璃的本质是"采样谁"：

| backdrop | 内容 | 采样者 | 为什么这样分层 |
|---|---|---|---|
| `bgBackdrop`（CanvasBackdrop） | 纯背景渐变 + 光斑 | 页面卡片、按钮 | 只折射背景，不会采样到别的卡片（递归） |
| `contentBackdrop`（LayerBackdrop） | 背景 + 全部页面内容 | 底栏、弹窗 | 滚到玻璃下的记录会被真弯折 + 色散 |
| `dialogBackdrop`（LayerBackdrop） | 弹窗自己导出的合成结果 | 弹窗内部按钮 | 防止按钮把弹窗背后 18 行列表折进来 |

三个 CompositionLocal 对应三种语义：
- `LocalLiquidBackdrop`：就近采样，页面内用 bg、弹窗内被覆盖成 dialog
- `LocalContentBackdrop`：整页内容层，只有浮层用
- `LocalInContentLayer`：标记"我在内容层里"——弹窗挂在页面 composable 内部时，用它判断必须退回实色膜，否则会采样包含自己的纹理，几帧后糊成一团

⚠️ **玻璃浮层必须是内容层宿主的兄弟节点（画在之后），不能是子节点。**

## 五、核心参数表（`liquidGlassSurface`）

| 参数 | 默认 | 含义 / 取值经验 |
|---|---|---|
| `refract` | 10f | 折射高度 dp。8~12 是 iOS 26 量级；>16 边缘开始像鱼眼。底栏细长条给到 22~26 并开 depth |
| `frost` | 0.62 | 白雾浓度 0~1，**唯一控制"背后能不能看穿"的旋钮**。正文压上来 → 0.8+；底栏 → 0.55~0.65；装饰件 → 0.3 |
| `veilAlpha` | -1f | 实心膜厚度 0~1。内容容器（卡片）必须 ≥0.5，否则正文压在玻璃上读不清；不传则按 `0.04 + frost×0.22` 算（0.04~0.30） |
| `depth` | false | 体积弯折：中间也跟着一起弯。细长底栏必须开，否则只有上下两条边在动 |
| `tint` / `tintAlpha` | `#BFD4FF` / 0.10 | 冷调浸润，薄薄一层 |
| `showShadow` | true | **底栏 / 胶囊一律传 false**。Shadow.Default 半径 24dp，比底栏半高还大，细长条上下阴影叠成方块灰影 |
| `edgeWidth` | 0.7f | 边缘高光宽度 dp。底栏和胶囊传 0.42f（发丝线），弹窗/卡片用 0.7f。传 0 关掉 |
| `topHighlight` | true | 长条玻璃可以关，免得像塑料膜 |
| `exported` | null | 把"自己下面的合成结果"导出，供弹窗内部子玻璃采样 |
| `pressed` | false | 按下时整体提亮，缩放固定 0.985（缩小，注意和按钮相反） |

### 效果链的硬编码数值

```
lens:
  refractionHeight = depth ? max(refractPx, size.height * 0.5f) : refractPx
  refractionAmount = height * (depth ? 1.1f : 1.5f)
  chromaticAberration = true
blur:
  radius = (1f + frost * 13f).coerceAtMost(10f) dp   ← 基数从 3 降到 1，上限 10 防 GPU 崩
highlight:
  width = 0.7dp, intensity = 0.48f, angle = 45f, falloff = 0.95f
内壁反光:
  1.5dp 描边，顶部 alpha 0.30 → 0.09 → 0.025 → 底部 0.11（浅色）
  再叠 1dp 细亮线：顶 0.52 → 中 0.09 → 底 0.20
```

**顺序：先 lens 再 blur**。lens 会把 padding 设成折射高度（采样多取一圈），blur 只在这个外扩范围内生效，边缘不会糊出锯齿。

## 六、玻璃条 / 胶囊的自绘配方

### `glassBar`（底栏，26dp 圆角）

从上到下五层，全是 verticalGradient：
1. 本体：近乎清水，白 0.13 → 0.06 → 0.10（浅色）
2. 顶部漫反射带：占上部 45%，白 0.34 → 0.14 → 透明
3. 中间镜面高光：横向窄带在 17%~30% 处，白 0.17，暗示玻璃有弧面
4. 底部地面反光：76%~100%，白 0.13
5. 外沿 1dp 细线（顶亮底弱）+ 轮廓暗线 `Black × 0.055`——**白玻璃压白背景必须有暗线才看得出边界**

### `glassPill`（选中胶囊）

- 按下放大到 **1.39 倍**（官方配方，1.04 太拘谨看不出被捏起来）
- squash & stretch：横向随速度拉伸、纵向反向压扁，松手回弹
- **绝对不能用 `Modifier.clip(shape)`**——它底层创建矩形离屏层，和父级离屏层叠出灰方块。改用绘制阶段 `clipPath(outline) { ... }`，零离屏
- `clipPath` 只裁玻璃本身，**不裁 `drawContent()`**（在裁剪块里调 drawContent 真机会抛异常闪退）
- 尺寸保护：宽/高 ≤0.5px 时跳过 Path 构造
- 顶部反射是一条**填充**亮带（白 0.60 → 0.18 → 透明），不是描边——描边只有 1px，真实玻璃上沿有宽度

## 七、平面按钮配方（`liquidGlassChip` → `glassStatic(flat=true)`）

全站按钮平面化后，只剩"一张薄面 + 一条细边"：

| 状态 | 白膜不透明度 |
|---|---|
| 禁用 | 0.06 |
| 默认 | 0.10 |
| 主操作 strong | 0.16 |
| 按下 | 0.20 |

Web 对照：`.glass-btn` = `rgba(255,255,255,0.10)`，hover 0.16。

描边（2026-11-04 两次加深）：普通按钮 `Color(0xFF0F172A) × 0.30`（浅）/ `White × 0.34`（深），1dp。**不加深时整排按钮看起来就是几团白雾。**

语义三态（对齐 Web）：
| 态 | 底 | 边 |
|---|---|---|
| 危险 `danger` | 淡红 `#FEE2E2 × 0.45`（深 `#460F14 × 0.20`） | `#DC2626 × 0.9` |
| 实心危险 `solidDanger` | `#EF4444 × 0.85` | 红 0.95 + 白字 |
| 正向 `positive` | `#16A34A × 0.16` | 绿 0.5 |

## 八、能力降级（四档，应用侧不写 if）

| 档位 | 条件 | 表现 |
|---|---|---|
| 真实折射 + 磨砂 | API ≥ 33 | lens + blur + 高光全开 |
| 磨砂模糊 | API 31~32 | lens 库内部 return，只有 blur + 高光 |
| 厚玻璃 | API ≤ 30 / 软件渲染 | 纯 Canvas 画：近实心 ≥0.96 + 描边 + 高光 |
| 已关闭 | 用户关开关 | `emptyBackdrop()`，只有染色 + 高光，零风险 |

关键守卫：
- `gpuEffectsUsable`：API ≥31 且**不是软件渲染**（RuntimeShader 要求硬件画布）。不满足**早退**，不能"试一下再 catch"——RuntimeShader 报错发生在 Canvas 绘制里，抛出时半块玻璃已经画到屏幕上了。
- `lensBroken`：AGSL 是设备现编的，同一 shader 不同 GPU 驱动成功率不同。第一次失败后**永久跳过 lens**，用 `@Volatile` 而不是 state（绘制阶段写 state 会死循环）。
- `forceStatic`：连续崩溃后由 CrashGuard 打开，全站退回静态绘制。
- lens / blur 都必须包 try——个别 OEM 驱动在 draw 阶段抛 = 闪退。

> 静态档为什么要 0.96 近实心：没有模糊时半透白会让背后的字变成"淡淡的但清清楚楚的影子"，比全透更难看。宁可厚玻璃，不要糊字。

## 九、顶栏：真模糊 + 羽化收口

用户原话："顶栏的模糊过渡依然很丑……别切两条横条一弄就完事。"

- 之前盖一条 12dp 背景色→透明渐变，那是**盖色块**，不是材质。
- 正确做法：顶栏是一层真材质，采样底下滚动内容做高斯模糊（22dp，8dp 还能看出字影），下缘羽化淡出，内容能从玻璃底下划过。
- 玻璃一直铺到屏幕最顶（含状态栏），中间留缝会出现"状态栏一块、顶栏一块"的两段感。
- 白膜峰值从 0.62 降到 0.30（深 0.72→更低）：62% 白膜铺在 22dp 模糊上就是"一坨白色"。**不能再低到 0.16**：快速滚动时文字轮廓会透出来。
- 顶栏总高 68dp = 实体 50dp + 羽化 22dp。

## 十、性能优化（玻璃项目的生死线）

| 问题 | 解法 |
|---|---|
| 效果链 lambda 每次重组新建 → 绘制缓存全废，滚动掉帧 | `effects` / `highlightProvider` 用 `remember` 锁住；`shapeProvider` 用共享实例 |
| 按压缩放导致 Modifier 链长度变化 → 重建渲染层，旧离屏层残留成方块 | `graphicsLayer` **常驻链上**，按下只改 scale 参数 |
| 同屏 10 个玻璃按钮 → 10 个 shader + 10 层离屏，真机崩 | 按钮全平面自绘，只留一个大卡片用真 backdrop |
| 背景光斑每帧重绘 → N 层玻璃跟着重新采样 | 光斑位图只栅格化一次，只动 `graphicsLayer` 的平移/缩放，交给合成器 |
| 动画值在组合期读取 → 每帧重组 + 重建渐变 | 传 lambda，在绘制阶段取值 |

## 十一、调试顺序（出现视觉 bug 时）

1. 先确认**玻璃本体还在不在**——不许靠删玻璃解决问题。
2. 查附加物：离屏层（clip / shadow / innerShadow）→ 阴影半径 → 缩放链是否常驻 → 是否自采样 → 裁剪方式。
3. 查层级：浮层是不是内容层的兄弟节点？弹窗是不是挂在页面 composable 内部？
4. 查设备档位：`tierLabel()` 看当前走到哪一档；AGSL 有没有 `lensBroken`。
5. 最后才动参数，一次只动一个。

> 那条"方块" bug 前后修了六次，真凶依次是：点击涟漪 → 按压缩放链长度变化 → 阴影 24dp → 胶囊 `Modifier.clip` 离屏层 → 嵌套结构（浮层成了子节点）→ 弹窗第三层 clip。**没有一次是靠降低玻璃效果修好的。**
