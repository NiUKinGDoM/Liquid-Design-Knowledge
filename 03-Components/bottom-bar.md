# 底栏 / Bottom Bar

> 来源：`ui/AppChrome.kt` 第 83 行起。
> 这套语言里最"液态"的一块，也是方块 bug 的重灾区。

## 三层结构（兄弟节点，绝不嵌套）

```
Box（容器）
 ├─ ① 底栏玻璃本体（唯一有离屏层的，但它自己不动，也不含胶囊）
 ├─ ② 选中胶囊（会动 → 纯自绘，零离屏）
 └─ ③ 一格格内容 + 点击区（indication = null，无涟漪）
```

**胶囊和底栏必须是兄弟。** 之前把胶囊嵌进底栏离屏层里，移动时旧位置清不干净 → 屏幕上留方块。这是方块 bug 第五个真凶。

## 玻璃本体（`glassBar`）

- 26dp 圆角，高约 60dp——等于胶囊端头。
- 五层自绘渐变 + 暗色轮廓线（白玻璃压白背景必须扣边）。
- `showShadow = false`（24dp 阴影在细长条上糊成方块）。
- `edgeWidth = 0.42dp`（发丝线）。
- `depth = true`（细长条只有开体积弯折，才不是只有上下两条边在动）。
- **不挂 exportedBackdrop**——采自己会自折射。

## 选中胶囊（`glassPill`）

- `clipPath` 而非 `Modifier.clip`（后者矩形离屏层 → 方块）。
- `drawContent()` 放裁剪块外面（放里面会闪退）。
- 形变参数见 `04-Interaction/bottom-bar-motion.md`。

## 图标与交互

- 图标全部 **Filled**，不用 Outlined（同样 21dp 下实心看着大）。
- **再点一次当前 tab** → reselect 信号（自增计数）→ 各页面回最上层（记录页重置分页）。
- 按住移动超过 touch slop（约 8dp）接管拖拽，不等 500ms 长按。
- 切页时用 `liveCurrent`，不是首次组合时的 `current`（否则拖到概览松手会跳回去）。
- 切页时不要在 drag 回调里 `animateTo`。

## 严禁

- 胶囊嵌进底栏玻璃（方块）。
- `Modifier.clip` 裁胶囊（方块）。
- 默认 24dp 阴影（方块）。
- 底栏涟漪（胶囊本身有按下凸显，涟漪在玻璃上就是方块）。
- 点击"先缩 0.86 再弹回"（已撤掉，用户要的是形变本身）。
