# 顶栏 / Top Bar

> 来源：`ui/AppChrome.kt` 第 628 行起（`TopBar`）。
> 用户原话："顶栏的模糊过渡依然很丑……别切两条横条一弄就完事。"

## 正确做法：真材质 + 羽化收口

- 之前盖一条 12dp「背景色→透明」渐变——那是**盖色块**，不是材质。
- 正解：顶栏是一层真材质，采样底下滚动内容做**高斯模糊 22dp**（8dp 还能看出字影），下缘羽化淡出。
- 内容能从玻璃底下划过——各页面顶部留 `TopBarHeight` 内边距（含羽化带）。

## 参数

| 项 | 值 | 说明 |
|---|---|---|
| 实体高度 | 50dp | 原 46dp，标题涨到 22sp 后行高必须跟上 |
| 羽化带 | 22dp | 下缘模糊淡出 |
| 总高 | 68dp | 页面顶部留白用这个值，必须含羽化带 |
| 模糊半径 | 22dp | 太小等于没糊 |
| 白膜峰值 | 0.30 | 深色更低。从 0.62 降下来——62% 白膜铺在模糊上就是"一坨白色" |

⚠️ 白膜**不能再低到 0.16**：快速滚动时文字轮廓会透出来。0.30 是"不再打架"和"不透字"的平衡点。

## 两个易错点

1. **玻璃铺到屏幕最顶（含状态栏）**。在状态栏下沿留一道缝，会出现"状态栏一块、顶栏一块"的两段感。
2. **膜色必须和 App 背景最上面那条完全一致**，否则顶栏上沿和状态栏之间留缝。

## 帧率胶囊（`FpsBadge`）

1:1 对齐 Web `.fps-display`：

- 等宽字体（Monospace，全站 4 处之一）。
- 颜色随帧率变（用户："帧率胶囊的颜色变化你没做，加上"）——绿/黄/红对应流畅/一般/卡。
- 用户报"卡"时，这个数字比"感觉有点卡"有用得多。

## 自折射禁令

顶栏和底栏一样，**不能挂 exportedBackdrop 采自己**——否则采样的是自己录的那一层。详见 `07-Development-Rules/liquid-rules.md` 铁律 6。
