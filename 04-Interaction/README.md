## 三条交互铁律

1. **按住即拖**：超过 touch slop（约 8dp）就接管，不等 500ms 长按。用户："那个延迟让跟手从一开始就输了半拍。"
2. **不要变色块**：用户否掉了底栏按压底和常驻球——"不需要"，只留形变。
3. **点击异常不杀进程**：`SafeTap.run` 统一兜底，Toast 告知用户，堆栈落诊断文件。
