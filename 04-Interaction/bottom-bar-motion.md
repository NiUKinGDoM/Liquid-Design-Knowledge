# 底栏形变 / Bottom Bar Motion

> 来源：`ui/AppChrome.kt`（`pillScale` / `pressProgress` / `panelOffset`）。
> 公式思路来自 Kyant0/AndroidLiquidGlass 的 `LiquidBottomTabs`，量级经用户四次校准。

## squash & stretch 计算

```
v = 归一化速度（每秒跨过几整条底栏）
按 v 对胶囊做横纵反向缩放：横向拉伸 ↔ 纵向压扁
```

## 量级校准史（用户来回给三次反馈）

| 阶段 | 上限 | 用户反馈 |
|---|---|---|
| 官方 a=0.75 / A=0.20 | 25% | "太夸张了，一直在不和谐的跳动" |
| 0.025 / 0.035 | 3.5% | "再多一点，现在太不明显了" |
| 0.06 / 0.08 | 8% | "从 8% 调到 12%" |
| 0.09 / 0.12 | 12% | 最终值（100dp 胶囊宽变化 12dp），配独立速度平滑，体感收敛到一丁点 |

> ⚠️ 别只看数字。最终虽写了 12%，但有**两级平滑**兜着，实际观感是"一丁点"。直接照搬 0.09/0.12 而不加平滑会得到用户否掉的"夸张跳动"。

## 其他参数

| 参数 | 值 | 说明 |
|---|---|---|
| 按住放大 | 1.39 倍 | 官方配方，1.04 太拘谨 |
| 整条跟手位移 | 封顶 4dp | EaseOut，松手弹回，让"整条被拽"更真实 |
| 回弹 | dampingRatio = 1 | 临界阻尼，直接躺平不过冲 |
| 形变加在哪 | 整格 `graphicsLayer` | 只影响绘制，不影响测量和命中 |
| 按压底座 | 无 | 用户："把按压底删掉" |
| 点击先缩 0.86 | 无 | 用户："按下去的反馈"不对，撤掉 |

## 拖拽

- 按住后移动超过 touch slop（约 8dp）接管，不等 500ms（`detectDragGesturesAfterLongPress` 是旧的）。
- 速度采样从"这次拖动"重新开始，不带上次残余。
- 归一化到"每秒跨过几整条底栏"，不同 tab 数手感一致。
- 切页后用 `liveCurrent` 送胶囊到正确格子；不在 drag 回调里 `animateTo`。

## 兄弟节点（再说一次）

胶囊是底栏的**兄弟**，不是子节点。缩放链必须常驻——按下时增删层会重建渲染层，旧离屏层残留成方块。

详见 `07-Development-Rules/visual-bug-triage.md` 铁律 2、4。
