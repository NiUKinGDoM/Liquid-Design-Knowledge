# 开发规则 / Development Rules

> 这是"动手前必读"的分册。违反这些规则会重复踩已经踩过的坑。

## 文档索引

| 文档 | 内容 |
|---|---|
| `liquid-rules.md` | 12 条铁律 + 10 问排查（**主文档，最全**） |
| `review-checklist.md` | 提交前评审清单 |
| `visual-bug-triage.md` | 方块/闪退/模糊盖屏的专项排查 |

## 最高铁律（写在所有规则之上）

**液态玻璃不许瞎改，也不许删掉。** 这条是拿四轮返工换来的。修 bug 的正确顺序：保住玻璃本身 → 查附加物 → 只改那个出问题的附加物。

## 使用顺序

1. 做新界面前：读 `review-checklist.md`。
2. 出现视觉 bug：读 `visual-bug-triage.md`，按 10 问排查。
3. 想改玻璃参数：先读 `liquid-rules.md` 全部 12 条，确认不是在"削弱玻璃换稳定"。
