# 视觉 Bug 排查 / Visual Bug Triage

方块残影、自折射、模糊盖屏、闪退——按这个顺序查。**没有一次是靠删玻璃修好的。**

## 症状 → 先看

| 症状 | 先看 |
|---|---|
| 玻璃移动后留方块 | 离屏层数量 → 第 1/2/4 问 |
| 点击后冒灰块 | 涟漪 → 第 1 问 |
| 玻璃越来越糊 | 自采样 → 第 5 问 |
| 一坨白色盖住屏幕 | 白膜峰值 → 第 9 问 |
| 点一下就闪退 | 绘制阶段异常 → 第 6 问 |
| 滚动掉帧 | 绘制缓存 / 重组 → 第 10 问 |

## 十问清单（依次问）

1. **玻璃本体还在吗？** 不许靠删玻璃修 bug（最高铁律）。
2. **有几层离屏？** `Modifier.clip` / `shadow` / `innerShadow` / backdrop 自己——方块六个真凶里有三个在这里。
3. **Modifier 链结构变了吗？** 按下如果增删层 → 重建渲染层 → 旧位图残留。要常驻 `graphicsLayer` 只改参数。
4. **裁剪方式对吗？** 玻璃用 `clipPath`（绘制阶段），不是 `Modifier.clip`（创建矩形离屏层）。`drawContent()` 放裁剪块外面。
5. **有自采样吗？** 弹窗在 host 内部（`LocalInContentLayer=true`）却用真模糊？卡片采样了内容层？→ 退实色膜 / 用 bgBackdrop。
6. **绘制阶段会抛异常吗？** RuntimeShader 软件渲染早退、AGSL 失败 `lensBroken`、Path 尺寸保护、blur try。
7. **当前设备走到哪档？** `tierLabel()`——真实折射/磨砂/厚玻璃/关闭，不同档行为不同。
8. **阴影半径超过控件半高了吗？** 24dp 阴影在细长底栏上叠成方块 → `showShadow=false`。
9. **模糊/白膜过头了吗？** blur 上限 10dp、白膜峰值 0.30（低于 0.16 透字、高于 0.62 一坨白）。
10. **同屏几块玻璃？重绘频率？** 层数 × 重绘 = 崩溃根源。

## "方块"六个真凶（历史记录）

| 次 | 真凶 | 修法 |
|---|---|---|
| 1 | 点击涟漪（矩形边界，几百ms 淡出） | 全站 `indication = null` |
| 2 | 按压缩放改 Modifier 链长度 | `graphicsLayer` 常驻 |
| 3 | `Shadow.Default` 24dp > 底栏半高 | `showShadow = false` |
| 4 | `Modifier.clip` 创建矩形离屏层 | 改 `clipPath` |
| 5 | 浮层是内容层子节点，被录进 backdrop | 改兄弟节点 |
| 6 | 弹窗在 `drawBackdrop` 外又加 `.clip()` | 删多余 clip |

> 排障口诀：**先查离屏层数量。**

## 排查纪律

- 一次只改一个变量，改完真机验证。
- 不要"顺便降低玻璃效果"——那是被明令禁止的。
- 截图（fontScale=1）正常不代表真机正常，要在目标设备上复现。
- 修完更新 `liquid-rules.md` 和本文件——每个新 bug 都是新知识。
