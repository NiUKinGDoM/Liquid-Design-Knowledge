01 — PRINCIPLES

六条不可协商的原则

每一条都对应一次真实的返工。不是审美偏好，是拿"方块、闪退、不像一套东西"换出来的。

1

玻璃是地基，不许削弱换稳定

出问题时改附加物（离屏层、阴影、裁剪、缩放链），绝不降低玻璃效果本身。用户原话："我的折射呢？？？？"

2

文字只有黑白

主文字纯黑/纯白，层次靠 62% / 40% 透明度与字重。彩色只给背景、色带、图标，不给正文。

3

尺寸只有档位

圆角 6 档、字号 9 档、弹窗 3 档。新增组件只取值，不许现拍数字——防止"能跑但不像一套东西"。

4

按钮全平面，液态集中在浮层

普通按钮一张薄面 + 一条细边。液态质感只在底栏胶囊、顶栏、弹窗三处。

5

会动的自己画

会移动的玻璃走纯 Canvas 自绘、零离屏层；静止大浮层才用真 backdrop；一堆小按钮走平面。

6

性能是生存项

先算同屏层数再决定实现。同屏 10 个 shader 会崩——层数 × 重绘频率才是崩溃根源。

03 — LAYERS

视觉分层

层级不靠阴影 dp，靠玻璃材质与三层 backdrop 的关系。浮层必须是内容层的兄弟节点，不是子节点。

01
背景层 · Aurora 三光斑
蓝 / 粉 / 青，周期 4.4 / 4.8 / 3.6 秒互质——只动合成层，零重绘
02
内容层 · 卡片与列表
采样 bgBackdrop（纯背景），不采样内容——避免递归
03
浮层 · 顶栏 / 底栏 / 弹窗
顶栏真模糊 + 羽化，底栏自绘玻璃 + 胶囊，弹窗真折射 + 二次导出 backdrop
04
反馈层 · Toast / 按压 / 震动
Toast 用 Popup 保证盖在弹窗之上；点击异常统一兜底不杀进程
04 — MATERIALS

四种玻璃实现

不是重复代码，是成本分层。选错实现就是崩溃和方块的开始。

真 backdrop

liquidGlassSurface

lens 真折射 + blur + 高光。参数 refract / frost / veilAlpha 控制厚度与通透。

用于：弹窗、静止大浮层
自绘 · 零离屏

glassBar / glassPill

纯 Canvas 画五层渐变。会动的东西绝不能用 Modifier.clip（矩形离屏层 → 方块）。

用于：底栏玻璃条、选中胶囊
平面自绘

liquidGlassChip

一张薄面 + 一条 1dp 细边。白膜按状态 0.06 / 0.10 / 0.16 / 0.20 分档。

用于：所有按钮、一堆小件
淡框

glassPanel

白 0.05 底 + 白 0.11 边 + 20dp 圆角。"若隐若现的框"，用于页面分组块。

用于：卡片、分组容器

THE IRON RULE · 最高铁律
液态玻璃不许瞎改，也不许删掉。

这条是拿四轮返工换来的。修 bug 的正确顺序永远是：保住玻璃本身 → 查附加物 → 只改那个出问题的附加物。任何"把折射删了换稳定"的方案都是错的。
